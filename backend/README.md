# Backend (API y base de datos)

API y base de datos compartida por los 3 módulos. Tecnología todavía **por definir en equipo** (ver [`/docs/BASE_PROYECTO_PASEO.md`](../docs/BASE_PROYECTO_PASEO.md) sección 3) — a cargo de la Persona 3 (líder técnico) como dueña de la base/login/API compartida; las rutas específicas de cada módulo (PaseoYa, Points, Jarvis) las implementa cada pareja sobre esa base.

Modelo de datos y rutas exactas (nombres de tablas/campos/estados a respetar tal cual) en la sección 4-6 del documento base.

Implementado con **Django + Django REST Framework** (JWT, SQLite en local / PostgreSQL en producción). Arranque, apps y rutas en el [README principal](../README.md).
