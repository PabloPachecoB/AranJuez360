# App cliente (React Native)

App móvil del cliente, compartida por los 3 módulos: marketplace PaseoYa, puntos/recompensas (Paseo Points) y chat con Jarvis.

Pantallas de PaseoYa (Persona 1): inicio con categorías y promociones, lista de negocios, catálogo por negocio, buscador global, carrito, mis pedidos con estado y QR de retiro. Ver contrato de rutas en [`/docs/BASE_PROYECTO_PASEO.md`](../docs/BASE_PROYECTO_PASEO.md) sección 6.

Implementada con **Expo / React Native**: registro con verificación de correo, login con doble autenticación y acceso con huella. Arranque en el [README principal](../README.md).
